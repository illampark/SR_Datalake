## 배포 후 점검 (생략 금지)

"컨테이너가 떴는가"가 아니라 **"데이터가 실제로 흐르는가"** 를 본다.

1. 배포된 이미지가 의도한 커밋인가
2. Benthos 가 응답하는가 — DB 의 `status` 가 아니라 `/ready`
3. 커넥터의 `last_collected_at` 이 배포 이후로 갱신되는가
4. 브로커 로그에 `being dropped` 가 새로 생기지 않았는가
5. 싱크 테이블 행수가 증가하는가

`scripts/verify-handoff.sh <env>` 가 1 · 2 · 3 · 4 를 출력한다.
