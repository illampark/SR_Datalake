## Ⅵ. 알려진 잔여 · 후속 검토

1. **gunicorn 4 workers 상태 불일치** (연쇄 알려진 회귀): `connector_workers._workers` 는 각 gunicorn worker 메모리에만 존재. start 요청 처리 worker 와 status/stop 요청 처리 worker 가 다르면 응답 불일치 가능.
2. **부팅 시 running collector 자동 복원 로직 없음**: sdl-app restart 시 DB 상 status=running 이어도 worker thread 는 재시작 안 됨. 사용자가 수동 stop-start 필요.
3. **`https://119.207.126.16:9443` 외부 접근 미검증**: Anthropic 클라우드·스테이징 서버 모두 timeout. 소스 IP 화이트리스트 가능성. 사용자 PC 브라우저에서 실 확인 필요.
